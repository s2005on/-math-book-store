# Repository access and workflow

- Repository: `s2005on/-math-book-store`
- Default branch: `main`
- Project stage: UI Foundation (`v0.2.0`)
- Reference project: [VNU Food Hola](https://github.com/s2005on/vnu-food-hola)

This repository is independent of the reference project. Keep project documentation, CI, tests, release notes, and deployment instructions versioned here.

The storefront currently provides a demonstration catalog and client-side cart only. Do not treat the demo checkout as a live order-processing system.
