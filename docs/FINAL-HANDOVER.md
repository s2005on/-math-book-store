# Final Handover Checklist

- [ ] Confirm lecturer/course/student details in report documents.
- [ ] Confirm all product titles, covers and prices with the seller.
- [ ] Run Python and Node test suites.
- [ ] Verify GitHub Actions on the release commit.
- [ ] Review screenshots and demo script.
- [ ] Confirm no secrets or raw source files are committed.
- [ ] Create release notes and tag after review.
- [ ] If deploying, configure domain, HTTPS, service user, Nginx and backups.
- [ ] Clearly state that order API, database, authentication and payment are out of scope until implemented.
