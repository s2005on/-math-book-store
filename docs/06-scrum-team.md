# Scrum Team and Working Agreement

## Roles
- Product Owner: project owner; confirms product scope, prices and acceptance criteria.
- Scrum Master / Project Coordinator: tracks backlog, risks, sprint review and documentation.
- Developer: implements storefront, API, database and integration.
- Tester: writes test cases, executes regression and records evidence.

For an individual academic project, one student may perform multiple roles. Record the actual assignment of work in TEAM.md; do not invent team members.

## Ceremonies
- Sprint planning: choose work with clear acceptance criteria.
- Daily check-in: record completed work, next task and blocker.
- Sprint review: demonstrate working features.
- Retrospective: identify one improvement for the next sprint.
