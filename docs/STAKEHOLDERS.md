# Stakeholder Register

| Stakeholder | Interest | Engagement |
|---|---|---|
| Lecturer | Academic requirements and evaluation | Confirm rubric and review milestones |
| Student/project owner | Delivery and demonstration | Plan, implement and maintain backlog |
| Book seller / content owner | Accurate book data, covers and prices | Confirm metadata and pricing |
| Student/customer user | Find suitable books and understand prices | Usability feedback and demo testing |

Actual names and contact details should be added only when confirmed.
