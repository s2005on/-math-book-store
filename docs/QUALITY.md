# Quality Management

## Quality goals
- Clear and responsive catalog experience.
- Consistent product metadata and cover assets.
- Safe handling of untrusted product strings in the browser.
- Repeatable local tests and CI.
- Honest labeling of demo-only workflows.

## Definition of Done
Code reviewed, relevant tests pass, no secrets committed, documentation updated, and behavior verified at desktop/mobile breakpoints. Backend features additionally require API tests, authorization checks and persistence tests.
