# MVP Demo Script

1. Open the storefront and explain the Math Book Store purpose.
2. Browse the sample catalog and explain class categories.
3. Search for a book and filter by class.
4. Open product details and show the cover mockup.
5. Add a priced book to cart, change quantity, remove a line and explain the total.
6. Open the demo checkout and explain that it does not send or save an order.
7. Open /admin.html and show the planned admin layout; point out that it is not authenticated or connected to a database.
8. Open /health and show the UI Foundation status.
9. Present tests, CI workflow, risks and next sprint backlog.
