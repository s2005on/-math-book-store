# Trạng thái đồng bộ LTD's Book Store

Cập nhật: 19/11/2026.

| Nguồn | Phiên bản | Trạng thái |
|---|---|---|
| Nhánh `main` | 0.5.1 | Mã nguồn đang có trên GitHub |
| ZIP do chủ dự án cung cấp | 1.3.0 Pro Edition | Mốc chuẩn cần nhập đầy đủ lên GitHub |
| GitHub Release 1.3.0 | Chưa có | Chưa phát hành |

**Chưa được phép coi mã nguồn GitHub là 1.3.0 cho đến khi nhập đầy đủ backend, frontend, ảnh, kiểm thử và merge Pull Request.**

## Việc còn lại

- [ ] Nhập mã nguồn và ảnh từ ZIP gốc 1.3.0 Pro Edition vào nhánh riêng.
- [ ] Đối chiếu file `VERSION`, README, ghi chú phiên bản và các tệp cấu hình.
- [ ] Loại bỏ script nhập bản cũ, tài liệu trùng lặp; giữ lịch sử Git.
- [ ] Không commit `.env`, cơ sở dữ liệu, `server/data/` hoặc thông tin cá nhân.
- [ ] Kiểm thử Python, JavaScript, giao diện và dữ liệu cũ trên đúng commit.
- [ ] Review và merge PR; không tạo tag hay GitHub Release trong đợt này.

Ghi chú 1.2.0 và 1.2.1 chỉ là tài liệu lịch sử, không phải mục tiêu đồng bộ hiện tại. Các vấn đề triển khai VPS phải được xử lý riêng để tránh thay đổi hệ thống đang chạy.
