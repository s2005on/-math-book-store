# Đồng bộ v1.3.0 Pro Edition

Nguồn nhập là bản ZIP v1.3.0 Pro Edition do chủ dự án cung cấp. Mã kiểm SHA-256 và kết quả thử riêng trên ZIP được ghi trong [hồ sơ Buổi 9](B9.md). Bản đồng bộ gồm ứng dụng, cấu hình mẫu, trình khởi động, bộ test, ảnh gốc và ảnh WebP phục vụ danh mục. Hướng dẫn nhập GitHub cho v1.2.0 nằm trong ZIP cũ được bỏ qua vì khóa cứng phiên bản.

Tài liệu Sprint 0 và các báo cáo trước đây phản ánh phiên bản tại thời điểm viết. Xem lịch sử `VERSION` để đối chiếu từng commit. Theo dõi kết quả kiểm tra bản GitHub ở [Actions](https://github.com/s2005on/LTDs-Book-Store/actions).
