# Tài liệu dự án

| Tài liệu | Nội dung |
|---|---|
| 01-project-charter | Mục tiêu, phạm vi, tiêu chí thành công |
| 02-requirements | Yêu cầu chức năng và phi chức năng |
| 03-system-design | Kiến trúc và luồng dữ liệu |
| 04-wbs | Phân rã công việc |
| 05-test-plan | Kế hoạch kiểm thử |
| 06-sprint-0-backlog | Sprint backlog |
| 07-demo-script | Kịch bản trình diễn |
| 08-release-checklist | Checklist phát hành |
| TEAM / STAKEHOLDERS | Vai trò và bên liên quan |
| QUALITY / RISKS | Chất lượng và rủi ro |
| VERIFICATION | Kết quả kiểm chứng |
| RELEASE-v0.2.0 | Ghi chú phát hành |

Dự án đang ở UI Foundation. Các chức năng backend và vận hành thương mại được ghi là backlog, không trình bày như đã hoàn thành.
