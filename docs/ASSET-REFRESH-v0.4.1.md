# Thay bộ ảnh sách nét — v0.4.1

## Thay ảnh catalog
1. Giải nén gói `math-book-store-book-assets-v0.4.1.zip` tại thư mục gốc repository.
2. Chép thư mục `server/web/assets/books/` vào đúng đường dẫn trong repo và ghi đè các file cùng tên.
3. Commit toàn bộ thay đổi ảnh lên nhánh triển khai.
4. Kiểm tra trang chủ và danh mục ở màn hình desktop lẫn điện thoại.

## Chất lượng ảnh
- Ảnh WebP quality 96, giữ độ phân giải nguồn.
- Ảnh bìa hiển thị bằng `object-fit: contain`, không cắt hoặc kéo méo.
- Upload trong trang quản trị được chuyển WebP quality 96.
